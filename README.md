# 🕉️ Dharma Gyan

**Dharma Gyan** is a spiritual video platform that brings together short and inspiring videos related to **Hindu Gods**. It aims to spread knowledge about Indian culture and spirituality through beautifully edited video clips.

![DharmaGyanDemo](https://github.com/KrishBharadwaj5678/DharmaGyan/raw/main/DharmaGyanDemo.png)

## ✨ Features

| Feature                    | Description                                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| 🎥 **Short Divine Videos** | Watch 30–60 second videos of various Hindu gods and mythological scenes.                              |
| 🕉️ **Spiritual Content**  | Includes videos from Mahabharata and divine gods like Krishna, Shiva, Vishnu, and more.                |
| 🌗 **Dark & Light Mode**   | Toggle between dark and light themes for a comfortable viewing experience.                            |
| 📥 **Video Download**      | Users can download their favorite devotional videos directly.                                         |
| ⚡ **Fast Performance**     | Built with ReactJS and TailwindCSS for speed and responsiveness.                                      |
| 📱 **Responsive Design**   | Fully optimized for mobile, tablet, and desktop screens.                                              |

## 🚀 Installation


### 1️⃣ **Clone the repository**

```bash
git clone https://github.com/KrishBharadwaj5678/DharmaGyan.git
```

### 2️⃣ **Enter Folder**

```bash
cd DharmaGyan
```

### 3️⃣ **Install Packages**

```bash
npm install
```

### 4️⃣ **Run App**

```bash
npm run dev
```
