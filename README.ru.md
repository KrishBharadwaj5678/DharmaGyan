# 🕉️ Дхарма Гьян

**Дхарма Гьян** это духовная видеоплатформа, которая объединяет короткие вдохновляющие видео о индуистских богах. Она создана для распространения знаний об индийской культуре и духовности через красиво смонтированные видеоролики.

![ДхармаГьянДемо](https://github.com/KrishBharadwaj5678/DharmaGyan/raw/main/DharmaGyanDemo.png)

## ✨ Возможности

| Функция                            | Описание                                                                                           |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- |
| 🎥 **Короткие божественные видео** | Смотрите видео длительностью 30–60 секунд с различными индуистскими богами и сценами из мифологии. |
| 🕉️ **Духовный контент**           | Включает видео из «Махабхараты», а также о богах Кришне, Шиве, Вишну и других.                     |
| 🌗 **Тёмная и светлая тема**       | Переключение между тёмным и светлым режимами для комфортного просмотра.                            |
| 📥 **Скачивание видео**            | Пользователи могут напрямую скачивать любимые духовные видео.                                      |
| ⚡ **Высокая производительность**   | Создано с использованием ReactJS и TailwindCSS для скорости и отзывчивости.                        |
| 📱 **Адаптивный дизайн**           | Полностью оптимизировано для мобильных устройств, планшетов и компьютеров.                         |

## 🚀 Установка

### 1️⃣ **Клонирование репозитория**

```bash
git clone https://github.com/KrishBharadwaj5678/DharmaGyan.git
```

### 2️⃣ **Переход в папку проекта**

```bash
cd DharmaGyan
```

### 3️⃣ **Установка зависимостей**

```bash
npm install
```

### 4️⃣ **Запуск приложения**

```bash
npm run dev
```
