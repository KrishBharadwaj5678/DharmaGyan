# 🕉️ DharmaGyan

**DharmaGyan** is a spiritual video platform that brings together short and inspiring videos related to **Hindu Gods**. It aims to spread knowledge about Indian culture and spirituality through beautifully edited video clips.

---

## ✨ Features

| Feature                    | Description                                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| 🎥 **Short Divine Videos** | Watch 30–60 second videos of various Hindu gods and mythological scenes.                              |
| 🕉️ **Spiritual Content**  | Includes videos from Mahabharata and divine gods like Krishna, Shiva, Vishnu, and more.                |
| 🌗 **Dark & Light Mode**   | Toggle between dark and light themes for a comfortable viewing experience.                            |
| 📥 **Video Download**      | Users can download their favorite devotional videos directly.                                         |
| ⚡ **Fast Performance**     | Built with ReactJS and TailwindCSS for speed and responsiveness.                                      |
| 📱 **Responsive Design**   | Fully optimized for mobile, tablet, and desktop screens.                                              |

---

## 🧰 Tech Stack

| Technology            | Purpose                                         |
| --------------------- | ----------------------------------------------- |
| **⚛️ ReactJS**           | JavaScript library for building user interfaces |
| **🎨 Tailwind CSS**      | Utility-first CSS framework for modern styling  |

## 🚀 Installation & Setup

###  1) Clone Repo

```bash
git clone https://github.com/your-username/DharmaGyan.git
```

### 2) Enter Folder

```bash
cd DharmaGyan
```

### 3) Install Packages

```bash
npm install
```

### 4) Run App

```bash
npm run dev
```
