# 🕉️ Dharma Gyan

**Dharma Gyan** é uma plataforma de vídeos espirituais que reúne vídeos curtos e inspiradores sobre deuses hindus. Seu objetivo é espalhar o conhecimento sobre a cultura indiana e espiritualidade por meio de clipes de vídeo cuidadosamente editados.

![DharmaGyanDemo](https://github.com/KrishBharadwaj5678/DharmaGyan/raw/main/DharmaGyanDemo.png)

## ✨ Recursos

| Recurso                      | Descrição                                                                               |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| 🎥 **Vídeos divinos curtos** | Assista a vídeos de 30 a 60 segundos de vários deuses hindus e cenas da mitologia.      |
| 🕉️ **Conteúdo espiritual**  | Inclui vídeos do Mahabharata e de deuses como Krishna, Shiva, Vishnu e outros.          |
| 🌗 **Modo escuro e claro**   | Alterne entre os temas escuro e claro para uma experiência de visualização confortável. |
| 📥 **Download de vídeos**    | Os usuários podem baixar diretamente seus vídeos devocionais favoritos.                 |
| ⚡ **Alto desempenho**        | Construído com ReactJS e TailwindCSS para velocidade e responsividade.                  |
| 📱 **Design responsivo**     | Totalmente otimizado para telas de celular, tablet e desktop.                           |

## 🚀 Instalação

### 1️⃣ **Clonar o repositório**

```bash
git clone https://github.com/KrishBharadwaj5678/DharmaGyan.git
```

### 2️⃣ **Entrar na pasta**

```bash
cd DharmaGyan
```

### 3️⃣ **Instalar dependências**

```bash
npm install
```

### 4️⃣ **Executar o aplicativo**

```bash
npm run dev
```
