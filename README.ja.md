# 🕉️ Dharma Gyan

**Dharma Gyan** は、ヒンドゥー教の神々に関する短く感動的な動画を集めたスピリチュアル動画プラットフォームです。美しく編集された動画クリップを通して、インドの文化と精神性の知識を広めることを目的としています。

![DharmaGyanDemo](https://github.com/KrishBharadwaj5678/DharmaGyan/raw/main/DharmaGyanDemo.png)

## ✨ 特徴

| 機能                   | 説明                                        |
| -------------------- | ----------------------------------------- |
| 🎥 **短い神聖な動画**       | さまざまなヒンドゥー教の神々や神話のシーンを30〜60秒の動画で視聴できます。   |
| 🕉️ **スピリチュアルコンテンツ** | マハーバーラタや、クリシュナ、シヴァ、ヴィシュヌなどの神々の動画を含みます。    |
| 🌗 **ダーク＆ライトモード**    | 見やすいダークモードとライトモードを切り替え可能です。               |
| 📥 **動画ダウンロード**      | 気に入った भक्तिपूर्ण（信仰的な）動画を直接ダウンロードできます。    |
| ⚡ **高速パフォーマンス**      | ReactJS と TailwindCSS により、高速でレスポンシブな設計です。 |
| 📱 **レスポンシブデザイン**    | モバイル、タブレット、デスクトップに完全対応しています。              |

## 🚀 インストール方法

### 1️⃣ **リポジトリをクローン**

```bash
git clone https://github.com/KrishBharadwaj5678/DharmaGyan.git
```

### 2️⃣ **フォルダに移動**

```bash
cd DharmaGyan
```

### 3️⃣ **パッケージをインストール**

```bash
npm install
```

### 4️⃣ **アプリを実行**

```bash
npm run dev
```
